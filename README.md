# Jira Vibrant Starter

Vite + React + Tailwind starter with a Jira-like Kanban board. Features:

- Drag & drop with react-beautiful-dnd
- Add/remove columns and cards
- Jira-style card UI: priority, labels, assignee initials, due date
- Light/dark theme toggle using Tailwind 'class' strategy
- Mocked frontend-only data (replace with API later)

Quick start:

```bash
npm install
npm run dev
```

Open http://localhost:5173

Demo data & credentials: none (frontend-only). Replace `src/services/api.js` to persist server-side.
